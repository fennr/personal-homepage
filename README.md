# personal-homepage

Личная страница [fennr.ru](https://fennr.ru): обычная версия для читателя и
терминальная — по запросу, из одного и того же контента.

Заменяет собой LiveTerm: тот эмулирует терминал и показывает контент как
файловую систему, но для читателя-человека это неудобно, а его сборка
(`npm install` + dev-сервер) тяжела для сервера. Здесь терминал остаётся, но
как второй режим, а не как единственный.

## Что уже есть

- Модель контента `content/*.toml` с проверкой инвариантов; ошибка называет
  файл и поле.
- Тесты: правила контента на битых входах и настоящий контент из репозитория.

Дальше по плану: обычная страница на htmx и Askama, терминальный режим,
Dockerfile и CI, выкат в homelab, снятие LiveTerm. Порядок шагов и принятые
решения — в [`docs/decisions.md`](docs/decisions.md).

## Структура

```
content/          profile.toml, stack.toml, experience.toml, projects.toml
src/content/      разбор, проверка правил, единая модель для обоих режимов
  date.rs         YearMonth и End ("now" у текущего места работы)
  model.rs        структуры TOML: deny_unknown_fields, Option для необязательного
  error.rs        ContentError/ContentErrors: «файл: поле: что не так»
tests/content.rs  настоящий контент и по одному тесту на каждое правило
docs/             решения и прототип дизайна
```

## Контент

Текст правится только в `content/*.toml`: шаблоны не содержат текста, а оба
режима читают одну модель. Правила:

- обязательные поля непустые;
- даты в формате `YYYY-MM`; у текущего места работы `end = "now"`, и оно идёт
  первым в файле;
- места работы — от нового к давнему;
- `emphasis` в группе стека обязан входить в её `items`;
- ссылки на проекты абсолютные, контакты — `https://`, `mailto:` или `/`;
- незнакомое поле — ошибка, а не молча проигнорированный текст.

## Разработка

```sh
just check            # форматирование, clippy -D warnings, тесты
just content-check    # проверить content/ так же, как это сделает сервис
just hooks            # хук commit-msg с commitlint (нужен node)
```

Сообщения коммитов — Conventional Commits, трейлер `Co-authored-by` запрещён.
Версия проекта живёт в `Cargo.toml`; node в CI не участвует.
