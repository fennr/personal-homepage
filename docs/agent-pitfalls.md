# Грабл: скрытие через фиксированное смещение

Симптом → правило:

- Элемент спрятан за край экрана через `top: -Npx`, а при увеличенном шрифте,
  text-only zoom или подмене шрифта вылезает обратно → прятать сдвигом на
  собственную высоту (`transform: translateY(calc(-100% - Npx))`,
  `clip-path: inset(50%)`), потому что высота зависит от шрифта, а константа —
  нет.

- Skip-ссылка ведёт в `<main>`, внутри которого лежит вся страница вместе с
  шапкой → пропускать нечего; вводный блок держать вне `main`, а цели давать
  `tabindex="-1"`, иначе фокус не переносится и следующий Tab идёт сначала.
