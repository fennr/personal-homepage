# AGENTS.md — personal-homepage

Правила этого репозитория. Общие правила агента описаны выше и здесь только
уточняются. Сначала прочитай `CONTEXT.md`: термины из него — контракт.

## Инварианты

1. **Текст — только в `content/*.toml`.** Русский текст в шаблонах допустим
   лишь как подпись интерфейса («Написать», «Опыт»). Новый абзац, пункт или
   описание проекта — это правка контента, а не шаблона.
2. **Оба режима читают одну модель.** Обычная и терминальная версии печатают
   данные из `Site`. Если для терминала нужен новый факт, он сначала
   появляется в модели и в правилах проверки, потом в обоих рендерах.
3. **Сервер без состояния.** Нет базы, сессий и cookies; история команд живёт
   в DOM. Если решение требует запоминать что-то между запросами — это
   изменение архитектуры, а не деталь реализации.
4. **JS только htmx, отдаётся из образа.** Никаких CDN, сборщиков и второго
   скрипта. Кликабельные подсказки в терминале и обычные формы — вместо
   клиентского кода.
5. **Ошибка контента называет файл и поле.** Сообщение вида
   `experience.toml: roles[3].end: ...` — часть интерфейса; «что-то не так»
   недопустимо.
6. **Тесты — через публичное поведение.** Правила контента проверяются на
   битых входах, HTTP-слой — запросами к приложению. Эталонных снимков HTML
   нет: они ломаются от правки текста.

## Перед коммитом

```sh
just check
```

Зелёный гейт — `cargo fmt --check`, `clippy -D warnings`, `cargo test`.
Сообщения коммитов — Conventional Commits, `Co-authored-by` запрещён.

## Что не делать

- Не добавлять зависимости ради одной функции: список зависимостей маленький
  намеренно.
- Не переносить в код тексты из резюме, минуя `content/`.
- Не добавлять маршрут, который отдаёт HTML без проверки контента на старте.
